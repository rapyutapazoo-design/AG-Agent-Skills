# Gitプッシュ自動化スキル (Git Deploy Assistant)

## 概要
現在作業中の未コミットの変更を抽出・レビューし、コミットメッセージを作成してリモートリポジトリへ安全にプッシュ（デプロイ）するためのアシスタントスキルです。

ソースコード内の機密情報や除外ファイルを検査する **3段階チェック（🔴 要修正 / 🟡 注意 / 🟢 問題なし）** と、プッシュ実行前にユーザーの承認を必須とする安全装置を備えています。

## ファイル構成
1. **`SKILL.md` (スキル本体)**
   4つのステップ（①ステータス確認 → ②セキュリティ・コーディング規約チェック → ③コミットメッセージ作成 → ④最終確認と実行）およびエラーハンドリングを定義しています。
2. **`references/security_rules.md`**
   🔴（プッシュ禁止）となるシークレットパターンや除外ファイル（`.env`, `*.pem`, `*.ppk`, `.clasprc.json`, `.handoff/` 等）の定義です。
3. **`references/coding_rules.md`**
   Kintone / GAS / Webフロントエンド向けの品質規約（🟡 注意項目）です。
4. **`assets/commit_template.md`**
   Conventional Commits に準拠したコミットメッセージのテンプレートです。

## 適用方法
リポジトリルートの [README.md](../README.md) の手順に従い、スキルディレクトリへ配置（シンボリックリンクまたはコピー）してください。
- Antigravity: `~/.gemini/config/skills/git-push-automation`
- Gemini CLI: `~/.gemini/skills/git-push-automation`

## 使い方（トリガーワード）
- `変更をレビューしてプッシュしてください`
- `コミットしてプッシュして`

（※コミット・プッシュを行わずレビューだけを行いたい場合は、`code-review` スキルの「レビューして」「差分を教えて」を使用します）
