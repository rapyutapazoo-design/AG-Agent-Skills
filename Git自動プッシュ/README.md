# Git自動プッシュスキル

## 概要
開発したコードのGitへのコミット、およびリモートリポジトリ（GitHubなど）へのプッシュ作業をシームレスに自動化し、作業の区切りで手軽にバックアップを取るためのスキルです。

## 適用方法
1. この `Git自動プッシュ` フォルダ内の設定やスクリプトを、エージェントのスキル用ディレクトリに配置します。
2. あらかじめ、対象のプロジェクトディレクトリで `git remote -v` が設定され、認証パスが通っている状態にしておいてください。

## 使い方
エージェントに対して、保存やバックアップに関する日常的な言葉で指示を出します。

例文：
- `これまでの作業内容をコミットしてPushしておいて`
- `〇〇の機能追加が終わったのでバックアップを取ってください`
