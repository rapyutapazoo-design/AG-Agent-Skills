# コミットメッセージ テンプレート

コミットメッセージは以下の Conventional Commits のフォーマットに準拠して作成してください。

## フォーマット

```text
<タイプ>[オプションのスコープ]: <簡潔な説明（日本語）>

[オプションの空行]

[オプションの詳細な説明（変更の理由や背景、影響範囲などを日本語で箇条書き）]
```

## 使用するタイプ（プレフィックス）

*   **feat**: 新しい機能の追加
*   **fix**: バグ修正
*   **docs**: ドキュメントのみの変更
*   **style**: コードの動作に影響しない、フォーマットなどの変更（空白、セミコロンなど）
*   **refactor**: バグ修正や機能追加を行わないコードの書き換え
*   **perf**: パフォーマンスを向上させるコードの変更
*   **test**: 不足しているテストの追加や既存のテストの修正
*   **chore**: ビルドプロセスや補助ツールの変更、ライブラリのアップデートなど

## 作成例

```text
feat(kintone): 部屋番号のバリデーション機能を追加

- 保存実行時（app.record.create.submit）に正規表現で半角数字3〜4桁をチェックする処理を実装
- エラー時に該当フィールドの下部にエラーメッセージを表示するように修正
```

```text
fix(gas): Googleフォーム連携時の日付フォーマットエラーを修正

- kintoneのDateフィールドへの送信フォーマットを YYYY-MM-DD に統一
```
