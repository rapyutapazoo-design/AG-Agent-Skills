# 実装プランナー (Implementation Planner)

## 概要
実装プランナーは、設計やアプローチが決定した後に、具体的な「実装計画書」を作成するためのアシスタントスキルです。
このスキルの特徴は、**コードの変更やコマンドの実行を行わず、純粋に手順の整理と計画に特化する**点にあります。これにより、AIが勝手にコードを書き換えて環境を壊すことを防ぎ、ユーザーが実装手順を事前に確認・承認できるようになります。

## 適用方法
1. この `implementation-planner` フォルダ内にある `SKILL.md` を、エージェントのスキル読み込みディレクトリ（例: `C:\Users\<ユーザー名>\.gemini\skills\implementation-planner\`）に配置します。
2. エージェントを再起動するかセッションを更新します。

## 使い方（トリガーワード）
チャット画面で、以下のキーワードを含めて指示を出してください。

> **「実装計画書」**

例文：
- `先ほど決めたアーキテクチャに基づいて、実装計画書を作成してください。`
- `ログイン機能追加のための実装計画書をお願いします。`

### 実行のワークフロー
1. AIが過去の文脈や指定された要件を読み取ります。
2. 以下の項目を含む計画書を出力します。
   - 実装のゴール
   - 対象となるファイル（新規・変更・削除）
   - ステップバイステップの実装手順
   - 懸念事項・ユーザーへの確認事項
3. この段階では実際のコード修正は行われません。計画内容に問題がなければ、通常のコーディングモードで「計画通りに実装を進めてください」と指示を出してください。
