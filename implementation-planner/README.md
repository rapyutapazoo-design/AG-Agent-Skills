# 実装プランナー (Implementation Planner)

## 概要
実装プランナーは、設計やアプローチが決定した後に、具体的なステップバイステップの「実装計画書」を作成するアシスタントスキルです。
**実際のコード変更やコマンド実行を行わず、手順・対象ファイル・リスク・完了条件の整理に特化する**ことで、実装着手前に計画を安全に確認・レビューできます。作成した計画書は `<リポジトリ>/.handoff/` に自動保存されます。

## 適用方法
リポジトリルートの [README.md](../README.md) の手順に従い、スキルディレクトリへ配置（シンボリックリンクまたはコピー）してください。
- Antigravity: `~/.gemini/config/skills/implementation-planner`
- Gemini CLI: `~/.gemini/skills/implementation-planner`

## 使い方（トリガーワード）
- **「実装計画書」**
- **「計画書を作成してください」**（「計画書を作って」も可）

### 実行のワークフロー
1. 直前の会話履歴、または別セッションで `<リポジトリ>/.handoff/` に保存された採用案（`kind: design`）を特定します。
2. 以下の6項目を含む計画書を出力します。
   1. 実装のゴール（採用案の名前・概要・採用理由）
   2. 対象となるファイル（新規 / 変更 / 削除）
   3. ステップバイステップの実装手順
   4. リスク・依存関係・注意点
   5. 完了条件（チェックリスト形式 `- [ ]`）
   6. 懸念事項・ユーザーへの確認事項
3. 計画書全文を `<リポジトリ>/.handoff/` に保存します（`kind: plan`）。
4. 計画内容に問題がなければ、「**実装してください**」と指示することで実装に進めます。
