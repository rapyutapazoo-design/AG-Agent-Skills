# AG-Agent-Skills

## 概要
AG-Agent-Skills は、Gemini CLI やその他の AI コーディングエージェントで使用できる拡張スキルを集めたリポジトリです。本リポジトリを利用することで、各種開発業務の自動化やコンサルティングなど、エージェントをより強力にカスタマイズできます。

## 基本的な適用方法（インストール）
本リポジトリ内のスキルをエージェントに適用するには、使いたいスキルのフォルダ（あるいは中身の `SKILL.md` など）を、ご利用のAIエージェントの所定のスキル読み込みディレクトリ（例: `C:\Users\<ユーザー名>\.gemini\skills\`）にコピー・配置してください。
