# システム設計コンサルタント (System Design Consultant)

## 概要
システム設計コンサルタントは、開発時の設計案、実装の構成案、問題の修正アプローチなどを自動的に比較検討し、専門家の視点から推奨案を提示するためのアドバイザースキルです。

このスキルの最大の特徴は**コードの変更やコマンドの実行を一切行わない（安全装置が働いている）**ことです。これによって、作業中の環境を意図せず破壊するリスクなしに、純粋な「壁打ち」や設計の相談を行うことができます。

## 適用方法
1. この `system-design-consultant` フォルダにある `SKILL.md` を、エージェントのスキル用ディレクトリ（例: `C:\Users\<ユーザー名>\.gemini\skills\system-design-consultant\`）にコピーして配置します。
2. エージェントを再起動するか、セッションを更新してスキルを読み込ませます。

## 使い方（トリガーワード）
チャットのリクエスト内に以下のフレーズを含めてください。

> **「～を検討してください」**

例文：
- `新規の予約管理システムのバックエンドアーキテクチャを検討してください。`
- `現在発生しているCORSエラーの解決アプローチを検討してください。`

### 出力フォーマット
実行すると以下のプロセスで論理的な回答が返却されます。
1. **要件と前提条件**: 目的や課題の整理（不明点は質問します）
2. **検討したアプローチ**: 可能な限り複数の解決案を提示し、メリット・デメリットを比較
3. **推奨案**: プロの目線からベストなアプローチを1つに絞り、その理由を説明
4. **今後の進め方**: 方針が決まった後の開発の進め方のアドバイス
