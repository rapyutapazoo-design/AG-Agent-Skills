# システム設計コンサルタント (System Design Consultant)

## 概要
システム設計コンサルタントは、開発時の設計案、実装の構成案、問題の修正アプローチなどを比較検討し、専門家の視点から推奨案を提示するアドバイザースキルです。

最大の特徴は**コードの変更やコマンドの実行を一切行わない（安全装置が働いている）**ことです。作業中の環境を意図せず変更するリスクなしに、純粋な「壁打ち」や設計の相談を行うことができます。採用が決まった案は `<リポジトリ>/.handoff/` に保存し、別セッションの計画書作成や自律実行へ引き継げます。

## 適用方法
リポジトリルートの [README.md](../README.md) の手順に従い、スキルディレクトリへ配置（シンボリックリンクまたはコピー）してください。
- Antigravity: `~/.gemini/config/skills/system-design-consultant`
- Gemini CLI: `~/.gemini/skills/system-design-consultant`

## 使い方

### 起動トリガー
- **「検討」**（「〜を検討してください」「検討して」を含む）
- **「方針を考えて」「何かアイデアある？」**

### モード継続と解除
- 起動中は各応答の冒頭に `⚠️ コンサルタントモード継続中` が表示されます。
- **採用案の保存**: 「推奨案で進めて」「案Bでお願いします」などで採用が確定すると、`<リポジトリ>/.handoff/` に採用案を保存します（[references/adoption_triggers.md](./references/adoption_triggers.md) / [references/handoff_format.md](./references/handoff_format.md)）。
- **モードの解除**: 「実装してください」「修正して」などの解除フレーズ（[references/release_triggers.md](./references/release_triggers.md)）を発話すると、採用案を保存したうえでコンサルタントモードを終了し、通常モードに戻ります。

### 出力フォーマット
1. **要件と前提条件**: 目的や課題の整理（不明点は質問します）
2. **検討したアプローチ**: 複数の解決案を提示し、メリット・デメリットを比較
3. **推奨案**: ベストなアプローチを1つに絞り、その理由を説明
4. **今後の進め方**: 計画書作成（`implementation-planner`）や実装着手への案内
