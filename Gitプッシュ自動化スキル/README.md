# Gitプッシュ自動化スキル (Git Deploy Assistant)

## 概要
現在作業中の未コミットの変更を自動で抽出・レビューし、コミットメッセージを作成してリモートリポジトリへ安全にプッシュ（デプロイ）するための高度なアシスタントスキルです。

単にGitのコマンドを叩くだけではなく、ソースコードに直書きされたパスワードやAPIキーなどの機密情報をコミット前に検知する「セキュリティチェック機能」と、プッシュ実行前にユーザーの承認を必須とする「安全装置」が備わっています。

## コアアーキテクチャ（動作の仕組み）
このスキルは、以下の3つのファイル群が連携することで安全な自動化を実現しています。

1. **`SKILL.md` (スキル本体)**
   エージェントが実行すべき4つのステップ（①ステータス確認 → ②セキュリティ規約チェック → ③コミットメッセージ生成 → ④ユーザー承認と実行）が定義されています。
2. **`assets/commit_template.md`**
   AIがコミットメッセージを生成する際のフォーマットの雛形です。
3. **`references/coding_rules.md`**
   コミット前に検査されるセキュリティルールやコーディング規約のリストです。APIキー等の認証情報の漏洩を未然に防ぎます。

## 適用方法
1. この `Gitプッシュ自動化スキル` フォルダ内にある全てのファイルを、エージェントのスキル読み込みディレクトリ（例: `C:\Users\<ユーザー名>\.gemini\skills\git-deploy-assistant\`）に配置します。
2. エージェントを再起動するかセッションを更新します。
3. 対象のプロジェクトで `git remote -v` の設定と認証が通っていることを確認してください。

## 使い方（トリガーワード）
チャット画面で、保存やバックアップに関する指示を出してください。

例文：
- `変更をレビューしてプッシュしてください`
- `今日の作業内容でコミットを作ってバックアップして`

### 実行のワークフローと安全装置
1. あなたの指示を受けると、AIが裏で `git status` と `git diff` を実行して差分を抽出します。
2. セキュリティチェックを行い、問題があればプッシュを停止して警告を出します。
3. 問題がなければコミットメッセージ案を作成し、**「プッシュ先のブランチ名」と「コミットメッセージ」を提示して、あなたに実行の最終承認を求めてきます。**
4. あなたがマニュアルで「OK」と合図した段階で初めて、自動的に `add`, `commit`, `push` を実行して処理を完了します。
